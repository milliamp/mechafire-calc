# Mecha Fire Resource Calculator

A community-built resource planning tool for [Mecha Fire](https://www.mechafire-mobile.com/). Track upgrade costs across buildings, Warbringer equipment, crystals, hero shards, and skill codexes. Includes an inventory tracker to see what you still need.

**Live app:** [milliamp.github.io/mechafire-calc](https://milliamp.github.io/mechafire-calc/)

## Structure

- `js/data.js` -- Game constants, costs, and hero roster. Edit this when game data changes.
- `js/app.js` -- UI logic, calculations, save/load.
- `css/styles.css` -- All visual styling.
- `index.html` -- Page structure.

No build tools required. Plain static files served via GitHub Pages.

## Contributing
